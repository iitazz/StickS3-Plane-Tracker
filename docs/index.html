Universal Plane Tracker — Web Flasher

Flash the latest firmware directly from your browser to an M5StickS3 or Freenove ESP32-S3 Display over USB. No PlatformIO or Arduino IDE required.

Connect your device over USB, then click the button below and select the matching serial port when prompted.

Your browser doesn't support Web Serial. Please use Chrome, Edge, or another Chromium-based browser. Web Serial is not available. Make sure you're viewing this page over HTTPS.

Before you start:

  • Use a data-capable USB cable (not charge-only).
  • Close any other program that might be using the serial port (e.g. PlatformIO monitor).
  • This performs a full flash, erasing any previously installed firmware.

This page is served from GitHub Pages and firmware images are rebuilt automatically from the repository's main branch.
